# 📁 Файл: frontend/js/i18n.js

## Что это такое?
Модуль интернационализации (i18n = internationalization, 18 букв между "i" и "n").
Отвечает за переводы на 4 языка: English, Русский, Հայերեն, ქართული.

Все другие модули вызывают `I18n.t('key')` чтобы получить текст на нужном языке.

---

## СТРУКТУРА объекта I18n

```js
const I18n = {
    currentLang: 'en',          // текущий язык
    languages: { en, hy, ru, ge },  // список поддерживаемых языков
    translations: {},            // переводы (загружаются из locale файлов)
    STORAGE_KEY: '11unity_language', // ключ в localStorage
};
```

## ФУНКЦИЯ: init() — инициализация

```js
init() {
    const savedLang = localStorage.getItem(this.STORAGE_KEY);
    const browserLang = navigator.language.split('-')[0];

    this.currentLang = savedLang ||
        (this.languages[browserLang] ? browserLang : 'en');

    document.documentElement.lang = this.currentLang;  // <html lang="ru">
    this.applyTranslations();
    this.createLanguageSwitcher();
},
```

**`navigator.language`** — язык браузера пользователя:
```
navigator.language  // → 'ru-RU' (Россия) или 'en-US' (США)
```

**`.split('-')[0]`** — взять только первую часть:
```js
'ru-RU'.split('-')   // → ['ru', 'RU']
'ru-RU'.split('-')[0] // → 'ru'
```

**Логика выбора языка (приоритеты):**
```
1. Сохранённый в localStorage (пользователь выбирал раньше)
2. Язык браузера (если поддерживается нами)
3. Английский по умолчанию
```

**`document.documentElement.lang = 'ru'`** — устанавливает атрибут `<html lang="ru">`.
Это важно для браузера, скринридеров, SEO.

## ФУНКЦИЯ: registerTranslations() — регистрация переводов

```js
registerTranslations(lang, translations) {
    this.translations[lang] = translations;
},
```

Эта функция вызывается из каждого locale файла:
```js
// frontend/locales/en.js
I18n.registerTranslations('en', {
    nav: { tournaments: 'Tournaments', teams: 'Teams' },
    common: { loading: 'Loading...' },
    // ...
});

// frontend/locales/ru.js
I18n.registerTranslations('ru', {
    nav: { tournaments: 'Турниры', teams: 'Команды' },
    common: { loading: 'Загрузка...' },
    // ...
});
```

После этого `this.translations` выглядит так:
```js
{
    en: { nav: { tournaments: 'Tournaments' }, ... },
    ru: { nav: { tournaments: 'Турниры' }, ... },
    hy: { ... },
    ge: { ... }
}
```

## ФУНКЦИЯ: t() — получить перевод

```js
t(key, params = {}) {
    const keys = key.split('.');
    let value = this.translations[this.currentLang];

    for (const k of keys) {
        if (value && typeof value === 'object') {
            value = value[k];
        } else {
            value = undefined;
            break;
        }
    }

    // Fallback к английскому
    if (value === undefined && this.currentLang !== 'en') {
        value = this.translations['en'];
        for (const k of keys) { ... }
    }

    // Параметры {name}, {count}
    if (typeof value === 'string' && Object.keys(params).length > 0) {
        return value.replace(/\{(\w+)\}/g, (match, paramName) => {
            return params[paramName] !== undefined ? params[paramName] : match;
        });
    }

    return value;
},
```

**Как работает обход вложенных ключей:**
```js
I18n.t('nav.tournaments')
// key = 'nav.tournaments'
// keys = ['nav', 'tournaments']

// Шаг 1: value = translations['ru'] = { nav: {...}, common: {...} }
// Шаг 2: value = value['nav'] = { tournaments: 'Турниры', teams: 'Команды' }
// Шаг 3: value = value['tournaments'] = 'Турниры'
// Результат: 'Турниры'
```

**Fallback к английскому:**
```js
// Если hy.json не имеет нужного ключа → берём из en.json
// Это защита от неполных переводов
```

**Параметры в переводах:**
```js
// В locale файле:
{ tournament: { teams_count: 'Teams: {count}' } }

// Использование:
I18n.t('tournament.teams_count', { count: 8 })
// → 'Teams: 8'
```

**`/\{(\w+)\}/g`** — регулярное выражение:
- `\{` — открывающая фигурная скобка
- `(\w+)` — слово внутри (захватывающая группа)
- `\}` — закрывающая скобка
- `g` — заменить все вхождения

## ФУНКЦИЯ: setLanguage() — сменить язык

```js
setLanguage(lang) {
    if (!this.languages[lang]) return;  // защита

    this.currentLang = lang;
    localStorage.setItem(this.STORAGE_KEY, lang);  // запомнить

    document.documentElement.lang = lang;
    this.applyTranslations();  // перевести весь DOM

    // Обновить кнопку переключателя
    currentLangSpan.textContent = this.languages[lang].nativeName;

    // Активный класс на выбранный язык
    document.querySelectorAll('.lang-option').forEach(btn => {
        btn.classList.toggle('active', btn.getAttribute('data-lang') === lang);
    });

    // Генерировать событие для main.js
    window.dispatchEvent(new CustomEvent('languageChanged', { detail: { lang } }));
},
```

**`classList.toggle('active', condition)`** — второй параметр boolean:
```js
btn.classList.toggle('active', true)   // добавить класс
btn.classList.toggle('active', false)  // убрать класс
```
Вместо if/else — коротко и чисто.

**`new CustomEvent('languageChanged', { detail: { lang } })`** — кастомное событие с данными:
```js
// CustomEvent позволяет передать данные в detail
window.dispatchEvent(new CustomEvent('languageChanged', { detail: { lang: 'ru' } }));

// В main.js:
window.addEventListener('languageChanged', (e) => {
    console.log(e.detail.lang);  // → 'ru'
    Tournaments.render();  // перерисовать с новым языком
});
```

## ФУНКЦИЯ: applyTranslations() — применить к DOM

```js
applyTranslations() {
    // data-i18n → textContent
    document.querySelectorAll('[data-i18n]').forEach(el => {
        const key = el.getAttribute('data-i18n');
        el.textContent = this.t(key);
    });

    // data-i18n-placeholder → placeholder
    document.querySelectorAll('[data-i18n-placeholder]').forEach(el => {
        el.placeholder = this.t(el.getAttribute('data-i18n-placeholder'));
    });

    // data-i18n-title → title атрибут (всплывающая подсказка)
    document.querySelectorAll('[data-i18n-title]').forEach(el => {
        el.title = this.t(el.getAttribute('data-i18n-title'));
    });
},
```

**Как это работает с HTML:**
```html
<!-- index.html -->
<a data-i18n="nav.tournaments">Tournaments</a>
<input data-i18n-placeholder="auth.email_placeholder">

<!-- После applyTranslations() на русском: -->
<a>Турниры</a>
<input placeholder="Электронная почта">
```

**Селектор `[data-i18n]`** — выбрать все элементы у которых есть атрибут `data-i18n`.
CSS атрибутные селекторы работают и в querySelector.

## ФУНКЦИЯ: createLanguageSwitcher() — создать UI переключателя

```js
createLanguageSwitcher() {
    if (document.getElementById('language-switcher')) return;  // уже есть

    const switcher = document.createElement('div');
    switcher.innerHTML = `
        <button class="lang-btn" id="lang-btn">
            <i class="fas fa-globe"></i>
            <span id="current-lang-name">${this.languages[this.currentLang].nativeName}</span>
        </button>
        <div class="lang-dropdown" id="lang-dropdown">
            ${Object.entries(this.languages).map(([code, info]) => `
                <button class="lang-option ${code === this.currentLang ? 'active' : ''}"
                        data-lang="${code}">
                    ${info.nativeName}
                </button>
            `).join('')}
        </div>
    `;
},
```

**`Object.entries(obj)`** — преобразует объект в массив пар [ключ, значение]:
```js
Object.entries({ en: {...}, ru: {...} })
// → [['en', {...}], ['ru', {...}]]

// Потом .map([code, info] => ...) — деструктуризация пары
```

**`.map(...).join('')`** — создать HTML для каждого языка и соединить:
```js
['en', 'ru', 'hy', 'ge'].map(code => `<button>${code}</button>`)
// → ['<button>en</button>', '<button>ru</button>', ...]
.join('')
// → '<button>en</button><button>ru</button>...'
```

**Тернарный оператор в шаблоне:**
```js
`${code === this.currentLang ? 'active' : ''}`
// Если текущий язык → класс 'active', иначе пустая строка
```

**`parentNode.insertBefore(new, reference)`** — вставить элемент перед другим:
```js
navActions.parentNode.insertBefore(switcher, navActions);
// nav (parent)
//   ├── switcher  ← вставили здесь
//   └── navActions (reference)
```

## ФОРМАТИРОВАНИЕ ДАТ

```js
MONTH_NAMES: {
    hy: ['Հունվար', 'Փետրվար', ...],  // армянские названия
    ge: ['იანვარი', 'თებერვალი', ...], // грузинские названия
},

formatDate(dateString) {
    const date = new Date(dateString);
    if (isNaN(date.getTime())) return dateString;  // не дата → вернуть как есть

    // Для армянского и грузинского — ручное форматирование
    if (this.MONTH_NAMES[this.currentLang]) {
        const month = this.MONTH_NAMES[this.currentLang][date.getMonth()];
        return `${date.getDate()} ${month} ${date.getFullYear()}`;
        // → '15 Մայիս 2026' (армянский)
    }

    // Для английского и русского — toLocaleDateString
    const localeMap = { en: 'en-US', ru: 'ru-RU' };
    return date.toLocaleDateString(localeMap[this.currentLang], {...});
},
```

**Почему ручное форматирование для армянского и грузинского?**
Windows не всегда поддерживает `hy-AM` и `ka-GE` локали в `toLocaleDateString()`.
Решение: хранить массив названий месяцев и вставлять вручную.

**`date.getMonth()`** — возвращает 0-11 (январь = 0, декабрь = 11):
```js
new Date('2026-05-15').getMonth()  // → 4 (май!)
MONTH_NAMES.hy[4]  // → 'Մայիս' (Май по-армянски)
```

**`isNaN(date.getTime())`** — проверить что дата валидна:
```js
new Date('invalid').getTime()  // → NaN
isNaN(NaN)  // → true → вернуть исходную строку
```

## ❓ Вопросы с защиты

**Q: Что такое i18n и зачем?**
A: i18n = internationalization (18 букв). Система переводов. Позволяет показывать текст на нужном языке пользователя. Наш сайт поддерживает 4 языка: English, Русский, Հայերեն, ქართული.

**Q: Как I18n.t('nav.tournaments') находит перевод?**
A: Разбивает ключ по точке: ['nav', 'tournaments']. Затем идёт по объекту переводов: translations['ru'] → ['nav'] → ['tournaments']. Если не находит — fallback к английскому. Если и там нет — возвращает сам ключ.

**Q: Как работает смена языка?**
A: setLanguage(lang) сохраняет в localStorage, обновляет html.lang, вызывает applyTranslations() для статического текста, и dispatchEvent(languageChanged) для динамического контента (main.js перерисовывает все секции).

**Q: Почему для армянского и грузинского ручное форматирование дат?**
A: Windows не поддерживает hy-AM и ka-GE локали в toLocaleDateString(). Поэтому храним массивы названий месяцев вручную и вставляем нужный месяц через date.getMonth().

**Q: Как работают параметры в переводах ({count})?**
A: value.replace(/\{(\w+)\}/g, fn) — регулярное выражение находит все {что-то} в строке. Для каждого вхождения fn получает имя параметра и ищет его в объекте params. Если есть — подставляет значение.

**Q: Откуда берутся переводы в translations?**
A: Из locale файлов. Каждый файл (en.js, ru.js, hy.js, ge.js) вызывает I18n.registerTranslations('ru', {...}). Это заполняет объект translations. Поэтому locale файлы должны загрузиться ДО i18n.init().
